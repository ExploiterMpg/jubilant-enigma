# ADR-0005 — Economy and Progression Balance

Status: Proposed

## Context

The game has:

- Cash.
- Trader buy/sell prices.
- Trader reputation.
- Trader tasks.
- Loot values.
- High-tier Blacksite crates.
- Keycard access.

Prices and spawn rates are currently rough.

## Decision needed

Define target progression pacing.

## Open questions

- How many successful raids should it take to afford an M4?
- How rare should Blacksite keycards be?
- Should trader rep unlock better items?
- Should high-tier loot be sell-only, craftable, or usable?
- Should death remove equipped gear and backpack loot?
- Should insurance exist?

## Recommendation

Balance around short browser sessions:

- Common useful loot every raid.
- Valuable loot every 2-3 raids.
- Keycard every 5-8 raids on average.
- Blacksite success should feel like a major payout.

Trader rep should eventually unlock:

- Better mags.
- Better armor/helmets.
- Better medical supplies.
- Higher-value tasks.
