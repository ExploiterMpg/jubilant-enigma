# Architecture / Design Decision Records

These ADRs capture unfinished, undecided, or risky game-design/architecture topics for future Codex sessions.

Use these alongside:

- `app/docs/GAME_DESIGN.md`
- `app/docs/PROJECT_STATE.md`
- `app/docs/PROJECT_MEMORY.md`
- `app/docs/prd/`

Status vocabulary:

- `Proposed`: needs a decision.
- `Accepted`: decided but may not be fully implemented.
- `Deferred`: intentionally postponed.
- `Superseded`: replaced by another ADR.
