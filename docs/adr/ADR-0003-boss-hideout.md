# ADR-0003 — Boss Hideout and Boss Encounter

Status: Deferred

## Context

The map includes a hidden crew hideout shell.

The user explicitly requested:

- Add a little hideout for a boss.
- Do not add the boss yet.

## Decision

The hideout may exist as environmental foreshadowing and future encounter space.

No boss should be implemented until explicitly requested.

## Future boss considerations

When the boss is added, decide:

- Spawn chance.
- Spawn conditions.
- Patrol area.
- Voice/sound cues.
- Unique loot.
- Unique key or access requirement.
- Whether boss guards exist.
- Whether the boss can leave the hideout.

## Follow-up work

- Mark the hideout visually without making it too obvious.
- Add boss-themed loot later only after boss design is approved.
