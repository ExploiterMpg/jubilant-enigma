# Product Requirement Documents

PRDs describe what Extraction Zone features should do from the player and product perspective.

Use PRDs for:

- player-facing behavior,
- feature goals,
- acceptance criteria,
- out-of-scope boundaries,
- UX requirements.

Use ADRs instead for internal architecture, algorithms, persistence formats, or implementation tradeoffs.

- `PRD-0001-core-extraction-zone.md` — Core game/product requirements.
